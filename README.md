# Indian Flavours - Restaurant Website with AI Chatbot 🍛

A modern, responsive restaurant website for **Indian Flavours**, an authentic Indian cuisine restaurant. The website features a fully interactive menu, online table reservations, event booking, and an AI-powered chatbot assistant that handles customer queries about orders, menus, and reservations.

## 📖 About the Project

**Indian Flavours** is a restaurant website built to demonstrate how a traditional restaurant site can be enhanced with a conversational AI assistant. The chatbot answers customer queries in real time — from browsing the menu and placing orders to checking reservation availability and learning about the restaurant.

This project is ideal for:
- 🍽️ Restaurants wanting to add an automated customer service layer
- 💻 Developers learning how to integrate a chatbot into a static website
- 🎓 Students exploring front-end development + conversational UI

---

## ✨ Features

### 🏠 Website Features
- **Responsive Design** – Fully mobile-friendly layout powered by Bootstrap 5
- **Hero Section** – Eye-catching landing area with call-to-action buttons
- **About Section** – Restaurant story and core values
- **Why Us** – Highlights of what makes the restaurant unique
- **Dynamic Menu** – Filterable menu (Veg, Non-Veg, Desserts, Breakfast, Lunch, Dinner, Snacks) with:
  - Dish images with lightbox preview
  - Ingredients, calorie info, ideal serving size, and preparation time
  - Individual "Order Now" buttons
- **Specials Section** – Tabbed showcase of chef's specials (Biryani, Royal Thali, Seafood Platter, Vegan Delights, Dessert Extravaganza)
- **Events Section** – Swiper-powered slider for Birthday Parties, Private Parties, and Custom Events
- **Chefs Section** – Team profiles with social links
- **Book a Table** – Complete reservation form (name, email, phone, date, time, party size)
- **Gallery** – GLightbox-enabled photo gallery
- **Contact Form** – Customer enquiry form
- **Scroll-to-Top Button** – Smooth navigation
- **AOS Animations** – Smooth scroll-based animations throughout

### 🤖 Chatbot Assistant
- **Floating Chat Toggle Button** – Always accessible from any page section
- **Expandable Chat Window** – Clean, modern chat interface
- **Context-Aware Responses** – Answers questions about:
  - 📋 **Menu** – Dishes, ingredients, prices, veg/non-veg info
  - 🛒 **Orders** – Placing orders, order status, and recommendations
  - 📅 **Reservations** – Table booking availability and process
  - 🏢 **Restaurant Info** – Location, hours, specials, and more
- **Multi-Turn Conversation** – Retains context within a session
- **Typing Indicator & Message Bubbles** – Natural chat experience

## 🤖 Chatbot Capabilities

The chatbot handles the following types of queries:

| Query Type | Example User Input | Bot Response |
|------------|-------------------|--------------|
| **Greeting** | "Hi", "Hello" | Welcome message with menu options |
| **Menu Browsing** | "Show me the menu", "What dishes do you have?" | Lists categories & popular dishes |
| **Dish Details** | "Tell me about Paneer Tikka" | Ingredients, price, calories, prep time |
| **Veg/Non-Veg Filter** | "Show only veg items" | Filters veg items from the menu |
| **Ordering** | "I want to order Butter Chicken" | Confirms dish & initiates order flow |
| **Reservations** | "Book a table for 2 at 7pm" | Collects date/time/party size & confirms |
| **Hours & Location** | "What time do you open?" | Shares opening hours & address |
| **Specials** | "What are today's specials?" | Highlights chef's specials |
| **Events** | "Can I host a birthday party?" | Shares event packages & pricing |
| **Fallback** | Unrecognized input | Politely asks for clarification |
